# 歌学日语

一个可以安装到手机或桌面的日语学习 PWA，核心是用日语歌学会歌词里的单词和语法。

线上地址：<https://wdlin2.github.io/japanese-song-app/>

## 使用方式

直接打开 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 功能

- 歌词逐句学习：Lemon、打上花火、夜に駆ける、アイドル、Pretender、群青
- 单词拆解：每句歌词标出重点词、假名和中文意思
- 语法讲解：11 个基础语法，每个都带简单解释和可朗读例句
- 歌词填空：用听力判断歌词里少了哪个词
- 网易云联动：一键唤起网易云 App 播放原曲，或打开网易云网页搜索
- 网易云歌单同步：粘贴歌单链接或 ID，自动识别里面的日语歌
- 自动获取歌词：歌单里的新歌可以尝试直接抓取歌词并加入学习
- 新歌导入：粘贴“歌名 - 歌手”文本，或直接导入歌词逐句学习
- 30 天旅行计划：自动按出发日期生成，可以标记每天完成
- 动漫场景：6 个常见场景短句，附带语气提示和小测
- 单词卡：48 个高频旅行词，认识后标记掌握
- 假名练习：平假名、片假名、混合模式闪电测验
- 旅行短语：46 条按场景分类的短语，支持搜索和日语朗读
- 进度保存：全部使用浏览器 localStorage，刷新不会丢
- PWA：支持安装到主屏幕，安装后可以离线打开核心页面

## 安装到手机

在浏览器打开网站后：

- Android Chrome：地址栏会出现“安装 App”，点击即可
- iPhone Safari：分享按钮 → 添加到主屏幕
- 电脑 Chrome/Edge：地址栏右侧出现安装图标，点击安装

网易云联动依赖手机或电脑上已经安装网易云音乐 App；未安装时会自动打开网易云网页搜索。

## 部署到 GitHub Pages

项目已经包含自动部署配置，推送到 GitHub 后会自动生成公开网址：

1. 在 GitHub 新建一个仓库
2. 在仓库 Settings → Pages 里把 Source 设置为 `GitHub Actions`
3. 把当前项目文件推送到仓库的 `main` 分支
4. Actions 会自动构建并部署，完成后 Pages 会给出类似 `https://你的用户名.github.io/仓库名/` 的地址
5. 手机直接保存这个网址，以后访问不需要电脑开机

也可以使用 Cloudflare Pages 或 Netlify 免费部署，直接把整个项目文件夹上传即可。

## 导入新歌

打开“导入”页面：

1. 同步歌单：粘贴网易云歌单链接或纯数字 ID，App 会尝试读取并标记日语歌
2. 文本导入：如果同步失败，粘贴歌单文本，每行一首 `歌名 - 歌手`
3. 歌词导入：把要学的歌词粘贴进来，每行格式为 `日文 | 罗马音 | 中文`
4. 语法笔记：在“学习重点”里写下这课想掌握的语法点

网易云没有官方开放歌单接口，自动同步依赖公开代理，偶尔会不稳定；此时用文本导入和歌词导入仍然可以完整学习。

所有歌词只保留短片段，仅用于语言学习。发音使用浏览器内置语音合成，安装 PWA 后可以离线使用。
